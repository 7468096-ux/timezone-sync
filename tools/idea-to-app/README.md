# idea-to-app — из идеи в готовое приложение

Скилл для Claude. Пишете идею одной фразой — получаете приложение уровня Timezone Sync:
- логика с тестами;
- удобный интерфейс, где ответ показан первым;
- телефон и компьютер, светлая и тёмная тема;
- 10 языков с арабским справа налево;
- ссылки для обмена и синхронизация устройств без регистрации;
- счётчик пользователей и кнопка «на кофе»;
- версия внутри Claude и, если подключён GitHub, сайт на своём домене с HTTPS и автопубликацией.

## Как установить

**В Claude (claude.ai, приложение на компьютере или телефоне)**
1. Скачайте `idea-to-app.zip`.
2. Откройте **Settings → Capabilities**. Убедитесь, что включено **Code execution and file creation**.
3. В разделе **Skills** нажмите **Upload skill** и выберите `idea-to-app.zip`.
4. Включите переключатель у `idea-to-app`.

**В Claude Code**
Скопируйте папку `idea-to-app` в `~/.claude/skills/` (для всех проектов) или в `.claude/skills/`
нужного репозитория.

## Как пользоваться

Просто опишите идею, например:

> Сделай приложение, чтобы делить счёт в ресторане между друзьями: кто что заказал, чаевые, кто кому сколько должен.

Или вызовите скилл явно: `/idea-to-app трекер привычек с напоминаниями`.

Claude сначала покажет улучшенное техзадание, а потом сделает всё сам:
1. соберёт приложение;
2. проверит его в браузере;
3. опубликует;
4. пришлёт ссылку и короткий отчёт.

От вас понадобятся только действия, которые требуют вашего входа: регистрация в Cloudflare, покупка
домена, секрет в GitHub. Claude даст их пошагово, со ссылками.

## Что внутри

| Файл | Зачем |
|---|---|
| `SKILL.md` | порядок работы и правила (главный файл) |
| `references/` | дизайн-система, языки, обмен и синхронизация, публикация, чек-лист качества, уроки из истории Timezone Sync |
| `template/` | рабочая заготовка приложения со всей инфраструктурой |
| `scripts/new-app.mjs` | создаёт новый проект из заготовки |
| `scripts/i18n-add.mjs` | добавляет строки сразу на все 10 языков |
